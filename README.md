# 📱 😊 🔔 happyphone.eu.cc
Website for a VERY happy phone.

😊 ✨ 🌐 You can check this website out [here](https://happyphone.eu.cc)

## 🗂️ Website pages

- 🏠 `src/index.html` contains the homepage and phone mood buttons.
- 🚨 `src/alert.html` contains the alert page and its action button.
- 😊 😐 😠 😢 The homepage offers happy, neutral, angry, and sad phone choices.

## 🛠️ Explore locally

📂 Open the HTML files to inspect their markup, styles, and scripts. Links to Discord and other external services keep their existing destinations. 🔗

## ✨ Interface details

🌈 Decorative emoji accompany the existing headings and controls. Text labels remain present, and decorative spans are hidden from assistive technology. ♿
